Formulation & Grounding

Documentation: Base64 text parsing validating presence of Install, Usage, API reference, Code blocks, and Licensing.
Test Ratio: Traverses repository tree: ratio = N_tests / N_source. Scaled via min(100, ratio × 250).
Commit Hygiene: Length validation (>10 chars), non-generic regex filtering, Conventional Commits format bonus.
Collaboration: Log-normalized metric: log₂(1+stars)×5 + log₂(1+forks)×8 + issues.
